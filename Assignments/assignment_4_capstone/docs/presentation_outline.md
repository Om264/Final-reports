# 5-Minute Demo Presentation Outline

## Slide 1: Problem Statement (45s)
Reservoir Dispatch During Drought: 7-day forecast, ecological flow (10 m3/s) vs hydropower revenue.

## Slide 2: Architecture (45s)
5 modules: Reservoir, Optimizer, Constraints, Objectives, Validation. AI for code gen, human for verification.

## Slide 3: AI Collaboration (60s)
Right: scipy API, formula translation, tests. Wrong: unit conversion, sign convention, tolerances.

## Slide 4: Results (60s)
Optimal 7-day schedule showing release, storage, eco compliance, hydropower. All constraints satisfied.

## Slide 5: Tool Evaluation (60s)
DeepSeek R1 (reasoning), Claude 3.5 (code), Kimi (context). Best practice: use all three.

## Slide 6: Lessons Learned (30s)
1. AI excels at syntax and API
2. AI fails at dimensional analysis
3. AI ignores edge cases
4. Human expertise is final verification layer
